# Багцын гүйцэтгэлийн нэгтгэл — `selbe_bagts_guitsetgel_negtgel`

Зургаан шатны хяналт бүрэн өнгөрсөн **батлагдсан** гүйцэтгэлийн бүртгэл.

```
https://services.arcgis.com/HJzgwvlNIXssnQar/arcgis/rest/services/
  selbe_bagts_guitsetgel_negtgel/FeatureServer/169
```

⚠️ Энэ нь **нэг хүснэгтийн** гүн баримт. Системийн ерөнхий зураглал →
[`docs/SYSTEM.md`](SYSTEM.md).

Кодын ганц эх сурвалж: [`src/lib/services.ts`](../src/lib/services.ts) → `BAGTS_NEGTGEL`.
Бичдэг цорын ганц зам: [`src/lib/negtgelWrite.ts`](../src/lib/negtgelWrite.ts) → `registerApproved()`.
Уншдаг: [`src/lib/live.ts`](../src/lib/live.ts) → `loadPkgProgress()`.

---

## 1. Мөрийн утга

**Нэг мөр = НЭГ БАГЦЫН, НЭГ АГШНЫ батлагдсан гүйцэтгэл.**

`bagts_ner + burtgesen_ognoo` хосоор давтагдахгүй. `registerApproved()` нь
бичихийн өмнө яг энэ хосоор шалгаж, давхардсан бол шинэ мөр НЭМЭХГҮЙ —
ерөнхий менежер хоёр удаа дарах, сүлжээ тасарч дахин илгээгдэх нь бодит
тохиолдол.

## 2. Задаргаа ЭНД БАЙХГҮЙ

Блок, ажлын мөр, хувийн жин, WBS шатлал бүгд `Bagts_*` **бөглөх хуудсанд**
үлдэнэ. Энэ хүснэгт «хэзээ, аль багц, хэдэн хувь» гэсэн ЕРӨНХИЙ асуултад л
хариулна.

> ⚠️ Задаргааг давхарлавал нэг тоо хоёр эх сурвалжтай болж, аль нь үнэн
> болох нь эргэлзээтэй болно. Блокийн түвшний гүйцэтгэл хэрэгтэй бол
> [`src/modules/sheet/sheetRows.ts`](../src/modules/sheet/sheetRows.ts)-ээс
> шууд уншина.

## 3. Талбарууд

| Талбар | Төрөл | Утга |
|---|---|---|
| `burtgesen_ognoo` | Date | Агшны огноо — түүхийн тэнхлэг. Багц бүрийн СҮҮЛИЙН мөрийг үүгээр сонгоно |
| `bagts_ner` | String | «Багц 4-1» — бөглөх хуудасны бичиглэлээр. `bagtsKey()`-ээр нормчилж холбоно |
| `bagts_guitsetgel_huvi_1` | Double | Бодит гүйцэтгэлийн хувь (0–100) |
| `tolovlogoot_huvi` | Double | Тухайн огноогоор БАЙХ ЁСТОЙ хувь (0–100) — хоцрогдол эндээс |
| `bodit_obyom_1` | Double | Гүйцэтгэсэн обьём |
| `Tolovlogoot_obyom_1` | Double | Төлөвлөгөөт обьём |

> ⚠️ **`_1` дагавар нь санамсаргүй БИШ.** Талбарыг Integer-ээс Double болгохын
> тулд хасаад дахин нэмэхэд ArcGIS өөрөө залгасан. Нэрийг гараар засах
> боломжгүй тул үйлчилгээнд байгаагаар нь бичив — «цэвэрлээд» таамаглаж
> бичвэл чимээгүй хоосон утга уншина.

## 4. Хувь ба обьёмыг хэрхэн уншихгүй вэ

**Хувийг ЭНД дахин бодохгүй.** Бөглөх хуудасны «Б. БАРИЛГА УГСРАЛТЫН АЖИЛ»
мөр нь дэд үе шатуудаа ЖИНГЭЭР нь аль хэдийн нэгтгэсэн байдаг — түүнийг
шууд авна. Энд өөрсдөө дундажлавал жин алдагдаж, дэлгэц дээрх тоо
хоорондоо зөрнө.

**Обьёмыг багц хооронд НИЙЛҮҮЛЭХГҮЙ.** Багцын түвшинд нэгж нь ХОЛИМОГ
(м³ бетон + м² хана + ш цонх) тул нийлбэр нь физик утгагүй. Харьцуулахдаа
ЗӨВХӨН өөртэйгөө: `bodit_obyom_1` ↔ `Tolovlogoot_obyom_1`.

## 5. Хоосон байдлыг зөвшөөрөх

Бөглөлт үе үе тасалддаг тул дуудагч тал **ҮРГЭЛЖ** хоосон хариуг
зөвшөөрөх ёстой. `loadPkgProgress()` нь хоосон массив буцаахад дэлгэц
«мэдээлэлгүй» гэж харуулна — 0% гэж будвал «эхлээгүй» гэсэн худал
мэдээлэл болно.

## 6. Бүртгэлийн хамгаалалтууд (2026-10-09)

`registerApproved()` бичихийн өмнө дараах дүрмүүдийг мөрдөнө. Бүгд
[`src/lib/negtgelWrite.ts`](../src/lib/negtgelWrite.ts)-д `⚠️` тайлбартай.

**±20-ийн хамгаалалт.** Шинэ гүйцэтгэл нь тухайн багцын сүүлийн мөрөөс
(энэ агшин ба өнөөдрөөс хойшгүй) **20 нэгжээс илүү БУУРВАЛ** бичихгүй, ил алдаа
буцаана — гол зорилго нь хэмжээсийн алдааг (0–1-ийг 0–100 гэж) барих. Хүн
шийднэ; бодит бууралтыг хүн өөрөө нэгтгэлд засна.

**`comparablePct` — хуудсын олонлог өөрчлөгдсөн үед.** Хоёр хуудастай багцад
(9F + 12F) дүнд орсон хуудсын олонлог өөрчлөгдөхөд (жиш. 12F анх удаа
нийтлэгдэв) бүтэн дүн нь «буурсан» мэт харагддаг ч бодит бууралт биш. Тиймээс
±20-ийг сүүлийн мөрийн ӨДРӨӨС ӨМНӨ аль хэдийн хэмжилттэй байсан хуудсуудын
ОДООГИЙН утгаар жишнэ: олонлог ижил бол бүтэн дүнгээр, жишигдэх хуудас огт
байхгүй бол хамгаалалт алгасна. Хэмжээсийн алдаа хуудас бүрийг 100 дахин
багасгадаг тул дэд олонлогоор ч баригдана.

**Хоёр хуудастай багц — тайлагнаагүй хуудас 0%.** Багцын дүн нь хуудсуудын
«Б.» мөрийг БЛОКИЙН ТООГООР жигнэсэн дундаж. Хэзээ ч нийтлэгдээгүй эсвэл «Б.»
мөр нь хэмжигдээгүй хуудасны блокууд **0%** гэж орно (2026-10-01-ний шийдвэр
«тайлагнаагүй блок 0%» — дашбоардын `pkgProgressOf`-тэй нэг дүрэм). Гүйцэтгэлийн
баганатай блокгүй хуудас жин авахгүй. Батлагдаж буй хуудасны ӨӨРИЙН «Б.» нь
`null` бол дүн `null` — бичихгүй. Төлөвлөгөөт хувь мэдэгдэхгүй хуудас байвал
`planned` нь `null` (цоорхой, 0 биш).

**Блокгүй багц (5.x · 6.x · 10) — 25945ca-аас БӨГЛӨГДДӨГ.** Бөглөх урсгал
(FillNew · hyanaltDetail · hyanaltStore · ajilApply · ulsiinKomiss) нь
[`fillSchema(pkg)`](../src/modules/sheet/bagts.pkg.ts) (`loadSchema(pkg, { fill: true })`)-ээр
синтетик НЭГ блок авна: «Обьём (энэ удаа)» нэмэгдэл нь мөрийн `obyem_sum`-д
хуримтлагдаж, `Ажил_гүйцэтгэл` = `obyem_sum ÷ Обьём` (архивт ≤ 1; Обьёмгүй/0
мөр түгжээтэй, `null` хэвээр); бүлэг ба «Б.» мөр нь Excel-ийн
`SUMPRODUCT(C, L)`-тэй ижил (`computeAll`, n = 1). Тиймээс ямар нэг ажил
хэмжигдсэн бол «Б.»-ийн `Бодит_гүйцэтгэл` тоотой бөгөөд `registerApproved()`
түүнийг барилгын багцтай ЯГ ижил замаар (±20 · өдөрт нэг мөр) **жинхэнэ
гүйцэтгэл болгон бичнэ**. Блокгүй багц нэг хуудастай тул блокоор жигнэх
(`blendBlocks`) хамаарахгүй. Газрын зураг/дашбоард (`sheetRows` ·
`blockProgress`) опт-ингүй — блокгүй хэвээр.

- **Хураангуй уншигдсан ч юу ч хэмжигдээгүй** («Б.» `null`) үед л
  `{ ok: true, skipped: 'blockless' }` — алдаа БИШ, илгээлт «бүртгэгдсэн» гэж
  тэмдэглэгдэнэ (урьд нь «бүртгэл хүлээгдэж буй» хэвээр мөнхөд дахин
  оролддог байв), юу ч бичигдэхгүй.
- **Хураангуй уншигдаагүй** (агшин олдсонгүй · бүдүүвч/сүлжээ/үйлчилгээний
  алдаа) нь `skipped` БИШ — барилгын багцтай адил `{ ok: false, error }`
  буцаж, бүртгэл дахин оролдоно (түр алдааг «хэмжигдээгүй» гэж залгихгүй).

**Өдөрт нэг мөр (`dayRange`).** Давхардлыг ЯГ ms-ээр биш, ӨДРИЙН МУЖААР
(хамгийн ойрын UTC шөнө дунд ±12 цаг) таньна — хуучин жааз 16:00Z, шинэ нь
00:00Z тамгатай байсан ч нэг өдөр. Тэр өдрийн мөр байвал: утга ижил → давхар
дуудалт, юу ч хийхгүй; зөрвөл ТЭР мөрийг хамгийн сүүлийн баталгаагаар
**шинэчилнэ** (шинэ мөр нэмэхгүй). `null` талбар хадгалсан утгыг дарахгүй.

**Автомат синк 0 бичихгүй.** Хажуугийн `TUSUL_NEGTGEL` хүснэгтийн автомат
синк ([`src/lib/negtgelAuto.ts`](../src/lib/negtgelAuto.ts) → `measuredHousing`)
нэг ч блок нь хэмжигдээгүй багцын 0%-ийг хүснэгтэд БИЧИХГҮЙ — хэмжилтгүй багц
нь «эх сурвалжгүй» (`null` → хүний бичсэн утга үлдэнэ), 0 биш. Дашбоард дээр
тэр багц 0% харагдсаар (дэлгэцийн дүрэм), хүснэгт хөндөгдөхгүй.
