# Багцын гүйцэтгэлийн нэгтгэл — `selbe_bagts_guitsetgel_negtgel`

Дөрвөн шатны хяналт бүрэн өнгөрсөн **батлагдсан** гүйцэтгэлийн бүртгэл.

```
https://services.arcgis.com/HJzgwvlNIXssnQar/arcgis/rest/services/
  selbe_bagts_guitsetgel_negtgel/FeatureServer/169
```

Кодын ганц эх сурвалж: [`src/lib/services.ts`](../src/lib/services.ts) → `BAGTS_NEGTGEL`.
Бичдэг цорын ганц зам: [`src/lib/negtgelWrite.ts`](../src/lib/negtgelWrite.ts) → `registerApproved()`.
Уншдаг: [`src/lib/live.ts`](../src/lib/live.ts) → `loadPkgProgress()`.

---

## 1. Мөрийн утга

**Нэг мөр = НЭГ БАГЦЫН, НЭГ АГШНЫ батлагдсан гүйцэтгэл.**

`bagts_ner + burtgesen_ognoo` хосоор давтагдахгүй. `registerApproved()` нь
бичихийн өмнө яг энэ хосоор шалгаж, давхардсан бол шинэ мөр НЭМЭХГҮЙ —
ерөнхий менежер хоёр удаа дарах, сүлжээ тасарч дахин илгээгдэх нь бодит
тохиолдол.

## 2. Задаргаа ЭНД БАЙХГҮЙ

Блок, ажлын мөр, хувийн жин, WBS шатлал бүгд `Bagts_*` **бөглөх хуудсанд**
үлдэнэ. Энэ хүснэгт «хэзээ, аль багц, хэдэн хувь» гэсэн ЕРӨНХИЙ асуултад л
хариулна.

> ⚠️ Задаргааг давхарлавал нэг тоо хоёр эх сурвалжтай болж, аль нь үнэн
> болох нь эргэлзээтэй болно. Блокийн түвшний гүйцэтгэл хэрэгтэй бол
> [`src/modules/sheet/sheetRows.ts`](../src/modules/sheet/sheetRows.ts)-ээс
> шууд уншина.

## 3. Талбарууд

| Талбар | Төрөл | Утга |
|---|---|---|
| `burtgesen_ognoo` | Date | Агшны огноо — түүхийн тэнхлэг. Багц бүрийн СҮҮЛИЙН мөрийг үүгээр сонгоно |
| `bagts_ner` | String | «Багц 4-1» — бөглөх хуудасны бичиглэлээр. `bagtsKey()`-ээр нормчилж холбоно |
| `bagts_guitsetgel_huvi_1` | Double | Бодит гүйцэтгэлийн хувь (0–100) |
| `tolovlogoot_huvi` | Double | Тухайн огноогоор БАЙХ ЁСТОЙ хувь (0–100) — хоцрогдол эндээс |
| `bodit_obyom_1` | Double | Гүйцэтгэсэн обьём |
| `Tolovlogoot_obyom_1` | Double | Төлөвлөгөөт обьём |

> ⚠️ **`_1` дагавар нь санамсаргүй БИШ.** Талбарыг Integer-ээс Double болгохын
> тулд хасаад дахин нэмэхэд ArcGIS өөрөө залгасан. Нэрийг гараар засах
> боломжгүй тул үйлчилгээнд байгаагаар нь бичив — «цэвэрлээд» таамаглаж
> бичвэл чимээгүй хоосон утга уншина.

## 4. Хувь ба обьёмыг хэрхэн уншихгүй вэ

**Хувийг ЭНД дахин бодохгүй.** Бөглөх хуудасны «Б. БАРИЛГА УГСРАЛТЫН АЖИЛ»
мөр нь дэд үе шатуудаа ЖИНГЭЭР нь аль хэдийн нэгтгэсэн байдаг — түүнийг
шууд авна. Энд өөрсдөө дундажлавал жин алдагдаж, дэлгэц дээрх тоо
хоорондоо зөрнө.

**Обьёмыг багц хооронд НИЙЛҮҮЛЭХГҮЙ.** Багцын түвшинд нэгж нь ХОЛИМОГ
(м³ бетон + м² хана + ш цонх) тул нийлбэр нь физик утгагүй. Харьцуулахдаа
ЗӨВХӨН өөртэйгөө: `bodit_obyom_1` ↔ `Tolovlogoot_obyom_1`.

## 5. Хоосон байдлыг зөвшөөрөх

Бөглөлт үе үе тасалддаг тул дуудагч тал **ҮРГЭЛЖ** хоосон хариуг
зөвшөөрөх ёстой. `loadPkgProgress()` нь хоосон массив буцаахад дэлгэц
«мэдээлэлгүй» гэж харуулна — 0% гэж будвал «эхлээгүй» гэсэн худал
мэдээлэл болно.
