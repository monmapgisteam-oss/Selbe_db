# cashflow.csv · ipc.csv — бүтцийн дүрэм

Publish хийхдээ талбар бүрийн төрлийг **field-dictionary.csv**-ийн дагуу гараар
тохируулна — AGOL эхний 10 мөрөөс таамагладаг тул хоосон баганууд (guilgee2_dun
г.м.) String болж алдагдана. Огнооны талбарууд бүгд **Date only** төрлөөр.

## cashflow — нэг мөр = нэг гэрээний нэг үе

- `ue_torol` = `ГЭРЭЭ` (мастер, гэрээ бүрд яг 1) · `САР` · `ӨМНӨХ ШИЛЖҮҮЛСЭН`.
- **Мастер талбарууд зөвхөн ГЭРЭЭ мөрөнд** (ajliin_ner…nemelt_dun). Сарын мөр
  нэмэхэд зөвхөн: geree_id, ue_torol=САР, jil, sar, ангиллын 4 багана, мөнгөн дүн.
- Ангиллын 4 багана (angilal, bagts, ded_bagts, guitsetgegch) бүх мөрөнд
  гэрээнийхээ утгыг яг таг давтана — group-by нэг query-гээр гардаг.
- Түлхүүр: (geree_id, ue_torol, jil, sar) давтагдашгүй.
- Багц: `bagts` = үндсэн (БАГЦ-6), `ded_bagts` = дэд (БАГЦ-6.2); дэд хуваарьгүй
  бол хоёулаа ижил. Хоёулаа хоосон эсвэл хоёулаа бөглөгдсөн байна.
- Хэмжилтгүй (бүх мөнгөн багана хоосон) сарын мөр ХАДГАЛАХГҮЙ — мөр байна
  гэдэг нь тухайн сард хэмжилт бий гэсэн үг.
- Жилийн нийлбэр мөр ХАДГАЛАХГҮЙ — САР мөрөөс бодогдоно (давхар тоолол гаргадаг
  байсан тул хассан). Бодогддог багана (хувь, өссөн дүн, суутгалын томьёо,
  toloh_dun, ur_zoruu) мөн хадгалахгүй.
- Хоосон = мэдээлэлгүй, 0 = тэг гүйцэтгэл — хольж болохгүй.

## ipc — нэг мөр = нэг акт

- `dugaar` = цэвэр тоо; дэлгэцийн код = torol-оос (УРЬДЧИЛГАА→APC-n,
  ГҮЙЦЭТГЭЛ→IPC-n). `status` = актын ерөнхий төлөв.
- `guitsetgegch` нь гэрээтэй мөрөнд cashflow мастертай **үсэг бүрээр** тэнцүү
  (өөр бичлэг нэг компанийг хоёр болгож хуваадаг).
- net_dun/uldegdel хадгалахгүй — олгох дүн = guitsetgel_dun − 4 суутгал
  (zahialagch_hynalt_suutgal, ur_ergen_tololt, baritsaa, zohiogch_hynalt).
  Үлдэгдэл = тэр дүнгээс гүйлгээнүүдийг хасна.
- Гэрээний үнэ энд БАЙХГҮЙ — cashflow-ийн tosovt_ortog/geree_erh_dun-д байна.
  Актын дүнтэй нэг баганад холивол SUM 5 дахин хөөрөгддөг.
## Текстийн дүрэм

Нүдэнд мөр шилжилт/таб/давхар зай/zero-width тэмдэгт байхгүй; дугаарт зөвхөн
кирилл үсэг (А/1309 — латин A хориотой); огноо YYYY-MM-DD.

## Publish-ийн дараа (нэг удаа)

Domain-ууд (ue_torol, angilal, ipc.torol, status), монгол alias-ууд
(field-dictionary-ийн mongol_ner), editor tracking, delete protection асаана;
долоо хоног тутмын export-ыг нөөцлөлт болгоно.

## ⚠️ Excel-ээр НЭЭЖ ХАДГАЛАХГҮЙ

Excel энэ хоёр файлыг нээж хадгалахад ЧИМЭЭГҮЙ эвдэнэ (2026-08-31-нд бодитоор
тохиолдож, эх үйлчилгээнээс сэргээв): том дүн `3.73E+11` болж 3 орон үлдэнэ,
таслалын араас хойшхи орон тайрагдана, огноо `2025-08-05` → `8/5/2025` болно,
`01/79` гэсэн бичгийн дугаар `Jan-79` огноо болно. Үзэх бол Notepad++/VS Code,
эсвэл Excel-ийн «Data → From Text/CSV» (багана бүрийг Text болгож) ашиглана.
