# Хуваарийн сарын обьём — `huvaari_obyem`

Мөр бүр = **нэг багц · нэг ажил · нэг блок · нэг сар**.

- `huvaari_obyem.csv` — ArcGIS Online-д **ачаалж хүснэгт үүсгэх** темплейт (толгой + 2 жишээ мөр).
- `field-dictionary.csv` — талбар бүрийн утга (`docs/fin-csv`-ийн жишгээр).

## ⚠️ EXCEL-ЭЭР БҮҮ НЭЭ

Excel энэ файлыг нээхэд утгыг нь ЧИМЭЭГҮЙ хөрвүүлнэ:

| багана | файлд | Excel болгодог |
|---|---|---|
| `blok` | `5/1` | **`1-May`** (огноо) |
| `sar` | `2025-10-01` | `10/1/2025` (M/D/YYYY) |

Excel-ээс хадгалбал өгөгдөл эвдэрнэ. Файлыг **ArcGIS Online руу шууд** оруул
(Content → New item → Your device).

## Ачаалахад анхаарах 4 зүйл

1. **`blok`-ийг ЗААВАЛ `String` болго.** Блокийн шошго `5/1`, `29/3` гэх мэт ташуу
   зураастай тул ArcGIS ч, Excel ч огноо гэж таамаглана. Огноо болбол апп
   блокийн нэрээ бичиж чадахгүй.
2. **`sar_txt`-ийг ЗААВАЛ `String` болго.** «2025-10» гэсэн утгыг мөн огноо гэж
   таамаглах магадлалтай. Огноо болсон тохиолдолд апп цагийн бүсээр гулсаж,
   буруу сар руу бичнэ.
3. **`obyem` ба `niit_obyem` нь `Double`.** Жишээ мөрүүдэд аравтын бутархай
   (`420.5`) байгаа нь яг үүний төлөө — бүхэл тоо байвал ArcGIS `Integer` гэж
   таамаглана.
4. **`sar` нь `Date`.** Формат `YYYY-MM-DD`, тухайн сарын 1-ний өдөр.

## Ачаалсны дараа

- **Индекс:** `dkey` дээр **unique**, `bagts,turul` ба `bagts,des_dugaar` дээр энгийн индекс.
  Индексгүй бол багц унших бүрд 60–120 мянган мөрийг бүтнээр сканнердана.
- **Editor Tracking** асаа — хэн хэзээ өөрчилсөн нь датад үлдэнэ.
- **Хуваалцах:** байгууллагад.
- Жишээ 2 мөрийг **устга** — зөвхөн төрөл таниулах зориулалттай.

## Холбоос

`des_dugaar` нь `Bagts_*` бөглөх хуудасны `Des_dugaar`-тай холбогдоно.
Тэр код нийтлэл бүрд **тогтвортой**: байгаа мөрийн код хэзээ ч дахин дугаарлагддаггүй,
шинэ мөрд `max + 1` олгогддог ([`sheetFrame.ts`](../../src/modules/sheet/sheetFrame.ts) —
«АЖЛЫН КОД — ЗӨВХӨН ДУТУУ мөрд олгоно»). 10 багц · 8,000 мөр дээр хэмжихэд 0 өөрчлөлт.
